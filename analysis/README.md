# Analysis

This directory contains the technical analysis performed during the Android Reverse Engineering & Security Analysis project.

The analysis focuses on understanding the application's architecture, AndroidManifest configuration, permissions, application control flow, and security posture through static reverse engineering techniques.

The documents in this directory summarize the key findings and observations made throughout the project.

> **Note:** This analysis was conducted in a controlled educational environment as part of an undergraduate Mobile Security course. All documentation is intended for educational and defensive security purposes.
