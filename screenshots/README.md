# Screenshots

This directory contains screenshots that illustrate the Android Reverse Engineering & Security Analysis project.

The screenshots demonstrate key stages of the analysis, including:

* AndroidManifest.xml analysis
* MainActivity reverse engineering
* Application component mapping
* APK decompilation using Apktool
* AndroidManifest modifications
* APK rebuilding process
* Device output verification

> **Note:** All screenshots were captured in a controlled educational environment as part of an undergraduate Mobile Security project. Sensitive information has been removed where appropriate.
